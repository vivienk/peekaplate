# Local captured-dish tilt demo

Generated by `peekaplate_processing.diner_demo`, which calls PR25's actual
`prepare_review_preview` processor against the user-supplied photo T0 manifest and
supplied grayscale mask. See `demo.json` for the processor's provenance, review
manifest, dish/revision identity and the exported delivery hashes/dimensions.
Regeneration instructions: [diner preview](../../../../../../docs/diner-portion-preview.md).

The cutout is re-encoded as WebP with an empty neutral background layer. The original
fallback JPEG is byte-identical to the verified T0 detail. No generated food pixels,
depth reconstruction, size or portion measurement. Shallow card tilt only.
The artifact remains needs_review and publication-ineligible. DEV-only imports keep
it out of production builds. Menu name, price and category are demo placeholders;
ingredients, allergens, capture date and publication rights remain unverified.
